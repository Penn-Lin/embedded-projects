## 功能

| 模块 | 内容 |
|---|---|
| 显示 | 128×64 OLED（I2C），两套动画：三角函数计算五角星顶点后连线填充、逐像素正弦波做旗面飘动 |
| 音频 | 无源蜂鸣器，三首乐谱的非阻塞播放 |

| 供电 | 双 18650 串联 + 过充过放保护板 |

## 核心问题：AVR 只有 2 KB SRAM

一张 128×64 单色全屏位图 = 128 × 64 / 8 = **1024 字节**，占掉一半 RAM，再叠加帧缓冲和栈，直接触发花屏与随机复位。

解法：

- 位图与曲谱全部加 `PROGMEM` 修饰符，编译期放进 Flash（32 KB）而不是 RAM
- 读取时改用 `pgm_read_word()` / `pgm_read_byte()` 从程序存储空间取
- 运行时只保留当前要画的一小段

这个项目让我第一次真正理解 AVR 的 RAM / Flash 双地址空间——两者地址独立，指针不能混用。

## 四级按键优先级

并发按键会互相打断，因此用 if 的先后顺序直接表达优先级：

```
总开关  >  位图显示  >  动画  >  音效
```

`loop()` 里从上到下依次判断，高优先级命中就 `return`，低优先级本轮不执行。

按键消抖用 `millis()` 时间戳，不用 `delay()`，否则动画会卡顿。
