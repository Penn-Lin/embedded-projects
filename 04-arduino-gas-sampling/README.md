## 它做什么

Arduino Nano 通过继电器驱动气泵，把待测气体抽过数字流量计，同步采集流量与温湿度（DHT11），经 HC-05 蓝牙每 2 秒回传手机。手机端也可以下发指令控制紫光灯与气泵，并回读执行状态。

## 硬件

| 部件 | 型号 / 接口 |
|---|---|
| 主控 | Arduino Nano（ATmega328P） |
| 流量计 | I2C 数字输出（带 CRC 校验） |
| 温湿度 | DHT11 |
| 通信 | HC-05 蓝牙串口 |
| 执行 | 继电器 × 2（气泵 / 紫光灯） |

## 软件结构

`loop()` 里跑两条互不阻塞的通道：

```
loop()
├── 每 2 秒：读流量 → CRC 校验 → 标定换算 → 读 DHT11 → 拼帧 → 蓝牙回传
└── 随时：   收到蓝牙指令 → 解析 → 执行 → 回状态
```

用 `millis()` 时间戳算差值，全文件没有一处 `delay()`，所以指令响应不会被采样周期卡住。

## 两个关键点

**1. 流量计读取三步缺一不可**

```
I2C 逐字节读 → CRC8 校验 → 线性标定（原始 AD → L/min）
```

校验不通过直接丢弃整帧，不让脏数据进入流程。CRC8 是手写的逐位异或 + 移位实现（`calcCRC8()`），因为流量计的校验多项式不在标准库里。

**2. 三类故障分别降级，任何一路异常都不中断采样**

| 故障 | 处理 |
|---|---|
| I2C 无应答 | 跳过本帧，计数 +1，继续下一轮 |
| CRC 校验失败 | 丢弃本帧，不上报 |
| DHT11 读空 | 温湿度字段填上一次有效值 |

## 指令集

ASCII 文本协议，便于用任意串口工具调试：

| 指令 | 作用 |
|---|---|
| `L1` / `L0` | 紫光灯开 / 关 |
| `P1` / `P0` | 气泵开 / 关 |
| `S` | 回读当前状态（气泵、紫光灯、流量、温湿度） |
